## 关于石朴

Seepure（石朴）是一个专注于**厨房与家居用品**的设计开发品牌。

**石朴**，音近 **Seepure**，而 See Pure 正是我们想做的一切——看见纯粹，看见朴素，看见生活本真。石，是大地最本真的材质；朴，是未经雕饰的自然状态。合而为一，便是一种生活态度：在喧嚣中守住内心的纯粹，在日常里看见朴素的珍贵。

我们**自主设计、自主开发、自主整合生产资源**，从一张草图到您手中的成品，每一个环节都由我们亲自把控。

## 设计哲学

每一件 Seepure 产品，都必须经得起三层追问：

### 见纯 · See Pure
去除一切非必要的装饰，让功能本身成为美学。不是"少"，而是"对"——只留下真正服务于体验的部分。

### 见朴 · See Simple
不掩盖材料的天然纹理、色差与瑕疵。木头有疤结，石头有裂纹，布有经纬——这些不是缺陷，是时间的指纹。

### 见生活 · See Life
设计不是为了第一眼惊艳，而是为了第一千次使用时依然顺手、依然安静、依然让你感到"就是它"。

> 这三句话是 Seepure 的宪法。任何产品，若不能回应其中至少两层，便不能进入 Seepure 的产品线。

---

## 设计原则

哲学是方向，原则是标尺。每一件 Seepure 产品在定稿前，必须用这四把尺子量一遍：

| 原则 | 核心 | 内涵 |
|:---|:---|:---|
| **克制** Restraint | 不多一笔，不少一笔 | 每一个元素的存在都必须有理由。没有"装饰性"元素，没有"为了好看而存在"的线条。 |
| **坦诚** Honesty | 该看见的都看见 | 接口、结构、材质边界不隐藏。不贴皮掩盖，不用油漆伪造纹理。 |
| **耐久** Endurance | 用旧了更好看 | 选择会随时间产生包浆、温润感的材料。问：五年后，这件东西还会被喜欢吗？ |
| **谦逊** Humility | 不抢戏，只陪伴 | 产品进入空间后应退后一步，成为生活的背景而非主角。 |

## 设计方法

从概念到成品的完整路径：

1. **场景凝视** — 去真实的厨房里待一天，从动作的不顺畅中发现设计起点
2. **本质追问** — 对每一个决策连问三个"为什么"，直到答案回归功能或体验
3. **材质对话** — 让材质引导设计，先触摸再画图，材质是合作者不是执行者
4. **原型试炼** — 快速制作可触摸原型，切一刀、放一瓶、洗一遍，找出设计谎言
5. **四尺量心** — 用克制、坦诚、耐久、谦逊逐一丈量，通不过就回炉
6. **诚实制造** — 设计师驻厂，确保图纸上的诚实在流水线上不被妥协

## 产品系列

### See Nature · 见自然
以蝴蝶、叶脉、年轮等自然元素为灵感，保留天然纹理与瑕疵，让材质本身成为设计的主角。

- 蝶翼刀座 · 叶脉玻璃器皿 · 年轮收纳

### See Form · 见形
几何极简，无冗余线条。接口与结构诚实可见，让功能定义形态。

- 极简餐具 · 几何灯具 · 收纳系统

### See Time · 见时
百年老木、手工玻璃、植物染织物——材料会随使用产生独特的包浆与变化，由你与时间共同完成。

- 传世家具 · 手工灯具 · 限量器皿
